# faygoLover's Network Tweaks (`flnettweaks`)

Сетевой мод для сборки S5 (Forge 1.20.1). Заменяет Connectivity. Ставится **и на сервер, и всем игрокам**: Forge не пустит на сервер без мода, потому что лимиты выше ванильных работают, только когда обе стороны их понимают.

## Что делает

**Лимиты** (`config/flnettweaks-common.toml`, раздел `limits`, одинаково на сервере и у игроков):

| что | ваниль | по умолчанию |
|---|---|---|
| пакет мода игрок → сервер | 32 КБ | 8 МБ |
| пакет мода сервер → игрок | 1 МБ | 32 МБ |
| пакеты входа (Forge: моды, реестры, конфиги) | 1 МБ | 32 МБ |
| пакет целиком | 8 МБ | 32 МБ |
| кадр в сети (после сжатия) | 2 МБ | 32 МБ |
| NBT в пакете | 2 МБ | 64 МБ |

**Вход по IP без обратного DNS** (клиент, с 1.0.3; вместо Fast IP Ping): если адрес сервера введён как IP, имя хоста — этот же IP, и пинг/проверка чёрного списка не спрашивают у DNS «чей это IP» (у некоторых провайдеров это секунды).

**Тайм-ауты** (`timeouts`): вход 300 с (ваниль 30), тишина в канале 120 с (30), ответ на keepalive 60 с (15).

**Понятные причины отключения.** Вместо `Internal Exception: io.netty...DecoderException` игрок и лог видят, что случилось:
> flnettweaks: пакет мода flnettweaks:test (мод faygoLover's Network Tweaks) (игрок → сервер) — 8.8 МБ, больше лимита 8.0 МБ. Поднимите limits.serverboundPayloadKB в config/flnettweaks-common.toml на сервере и у игроков

То же для NBT, распаковки, кадров, тайм-аутов («от сервера ничего не приходило 120 с, последнее: … N с назад») и keepalive. Ошибки соединения пишутся в лог как WARN (ваниль пишет их только в debug).

**Экран входа.** Под «Подключение…» и «Загрузка местности» видно:
- этап и время;
- сколько пакетов и данных пришло;
- последний пакет и его мод;
- прогресс большого пакета;
- реестры Forge N/M;
- через `slowStepSeconds` — жёлтая строка «Ждём: …» (сервер не отвечает, проверка аккаунта, сервер занят, применение реестров, чанк под игроком…).

**Хронология входа в логе.**
- Сервер: этапы входа, сколько сообщений Forge, на какое игрок дольше всего отвечал, трафик. Если этап завис — сразу WARN «чего ждём».
- Клиент: то же со своей стороны, плюс какой пакет дольше всего обрабатывался.

**Диагностика.**
- Пакеты от `bigPacketKB` (512 КБ) — в лог с каналом и модом.
- Пакеты, которые обрабатывались в основном потоке дольше `slowPacketMs` (500 мс), — в лог: так видно, какой мод тормозит вход или сервер.

**Команды.**
- `/flnet stats [in|out]`, `/flnet big`, `/flnet who`, `/flnet limits`, `/flnet reset` — сервер, уровень прав 2.
- `/flnetc stats|big|limits` — клиент.

**Устойчивость** (`tweaks`):
- ошибка подписи чата не выкидывает с сервера;
- обрезанная секция чанка не роняет клиент.

## Сборка и проверка

```
JAVA_HOME=".../jdk-17" ./gradlew build -x test     # build/libs/flnettweaks-*.jar
./gradlew runServer -PjoinDelay=15                  # dev: искусственная задержка входа 15 с
./gradlew runClient -Pquickplay=localhost:25599 -Pusername=Dev -Pautotest=true
```

Для компиляции нужен `libs/fancymenu_forge_3.9.6_MC_1.20.1.jar` (compileOnly, в git не лежит — положить вручную).

В dev включён `-Dflnettweaks.debug=true`: канал `flnettweaks:test`, команды `/flnet test <КБ>` и `/flnetc test <КБ>`.

Автотест проверяет три случая:
1. 100 КБ серверу — должно пройти, ваниль режет на 32 КБ.
2. 3 МБ в ответ — кадр больше ванильных 2 МБ.
3. 9 МБ серверу — должно быть понятное отключение.

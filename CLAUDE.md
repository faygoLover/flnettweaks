# faygoLover's Network Tweaks

Сеть сборки S5 (`flnettweaks`): лимиты, понятные причины отключения, ход входа, обрывы и переподключение, статистика, журнал, TLS. Семейство RP/FL/S5, Forge 1.20.1, Java 17. Отвечать по-русски.

## Прежде чем что-то добавлять
1. `../_family/FAMILY_MAP.md`, раздел 3 «Куда это положить» — нет ли готового механизма в RP Core или другого мода для этой задачи.
2. `docs/MAP.md`, раздел 4 — рецепт для твоего случая и образец, с которого списать.
3. `docs/INDEX.md` — поиск по слову: нет ли уже такого класса, события, команды.

Новый класс, пакет, пакет сети, команда, ключ конфига или поле состояния — обнови `docs/MAP.md` в том же
коммите и пересоздай указатель: `python ../_family/tools/mapgen.py "faygoLover's Network Tweaks"`.

## Нельзя
- Трогать игрока и мир из сетевых потоков (миксины конвейера работают в Netty).
- Менять лимиты так, чтобы клиент и сервер разошлись.
- Переименовывать ключи `flnettweaks-common.toml`.
- Зависеть от модов RP: мод самостоятельный.
- Push, выпуск сборки, правки живого сервера — только по прямому слову Алекса. Коммиты локальные.

## Команды
```
gradlew.bat build                                        # jar в build/libs
python ../_family/family.py verify "faygoLover's Network Tweaks"   # компиляция и связи (игровых тестов у мода нет)
```
